# Правила для агентов — Утка в пальто

## Основное правило

**Одна задача из PLAN.md за раз.** Агент берёт первую незавершённую задачу, выполняет только её и останавливается. Следующую задачу можно начинать только после ручной проверки результата человеком.

## Обязательная ручная проверка

После каждого изменения файлов агент сообщает, что изменение внесено, и ждёт подтверждения от человека. Без явного «ок» или «продолжай» агент не переходит к следующей задаче.

## Запреты

- Не создавать commit, push или публикацию без явной команды человека.
- Не менять больше одного файла за один шаг, если задача явно не требует нескольких файлов одновременно.
- Не добавлять возможности, не описанные в spec.md, — даже если они кажутся полезными.
- Не использовать внешние URL, фреймворки, пакетные менеджеры или системы сборки.

## Работа с `index.html`

Файл `index.html` является единственным артефактом сайта. Весь HTML, CSS и JavaScript должны быть встроены в него. Никаких отдельных файлов стилей или скриптов.
