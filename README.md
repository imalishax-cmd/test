# Утка в пальто

Одностраничная витрина бренда с интерактивным подбором образа.

## Суть проекта

Посетитель открывает страницу, знакомится с предложением бренда и нажимает кнопку «Подобрать образ». Страница случайным образом выдаёт одну из двух заранее заданных рекомендаций.

## Технические ограничения

- Один файл `index.html` — HTML, CSS и JavaScript встроены в него.
- Никакого фреймворка, бэкенда, базы данных или API.
- Никаких секретов и внешних изображений.

## Структура репозитория

```
test/
├── index.html   — готовый сайт (создаётся отдельным шагом)
├── README.md    — этот файл
├── spec.md      — наблюдаемые критерии готовности
├── AGENTS.md    — правила работы агентов
└── PLAN.md      — пошаговый план реализации
```

## Запуск

Откройте `index.html` в браузере — никакого сервера не нужно.
