# Спецификация — Утка в пальто

## Критерии готовности (Definition of Done)

Каждый пункт должен быть проверен вручную в браузере перед тем, как задача считается выполненной.

1. **Открытие без сервера.** Файл `index.html` открывается через `file://` в актуальных версиях Chrome, Firefox и Safari без ошибок в консоли.

2. **Отображение витрины.** На странице видны: название бренда «Утка в пальто», краткое описание предложения и кнопка «Подобрать образ».

3. **Первая рекомендация.** При нажатии на кнопку появляется блок с одной из двух заранее написанных рекомендаций (текст, стиль или набор вещей).

4. **Вторая рекомендация.** При повторных нажатиях кнопки хотя бы один раз за пять попыток появляется вторая рекомендация, отличная от первой.

5. **Только встроенные ресурсы.** Во вкладке Network браузера отсутствуют запросы к внешним URL — ни к шрифтам, ни к изображениям, ни к скриптам.

6. **Корректная вёрстка на мобильном.** При ширине окна 375 px ни один элемент не выходит за горизонтальный край, горизонтальный скролл отсутствует.

7. **Единственный HTML-файл.** Репозиторий содержит ровно один файл `index.html`; отдельных `.css` и `.js` файлов нет.
