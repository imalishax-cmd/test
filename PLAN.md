# План реализации — Утка в пальто

Каждый шаг выполняется отдельно и проверяется вручную перед переходом к следующему.

## Шаги

- [ ] **Шаг 1. Скелет страницы.**
  Создать `index.html` с корректным `<!DOCTYPE html>`, метатегами (`charset`, `viewport`), заголовком вкладки «Утка в пальто» и пустым `<body>`. Проверить: файл открывается без ошибок консоли.

- [ ] **Шаг 2. Секция витрины.**
  Добавить в `<body>` блок с названием бренда, коротким описанием (1–2 предложения) и кнопкой «Подобрать образ». Проверить: все три элемента видны на странице.

- [ ] **Шаг 3. Логика рекомендаций.**
  Встроить в `<script>` массив из двух рекомендаций и обработчик клика: случайно выбирает одну и показывает её в блоке под кнопкой. Проверить: оба варианта появляются при многократных нажатиях.

- [ ] **Шаг 4. Базовые стили.**
  Встроить в `<style>` минимальный CSS: читаемый шрифт, центрирование контента, отступы, цвет фона и акцентный цвет кнопки. Проверить: страница выглядит аккуратно при ширине 375 px и 1280 px.

- [ ] **Шаг 5. Финальная проверка по spec.md.**
  Пройти все 7 критериев DoD из `spec.md` вручную. Отметить пункты выполненными. Если что-то не проходит — вернуться к соответствующему шагу.
